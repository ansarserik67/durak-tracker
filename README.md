# 🃏 Дурак — счётчик выбывших карт

Веб-приложение для отслеживания карт, которые уже вышли из игры в «Дураке» (колода 36 карт).

## Возможности

- Все 36 карт русской колоды (6–Т, ♠ ♣ ♦ ♥): **каждая масть — отдельный ряд** с подписью и счётчиком («9/9»), чтобы на телефоне сразу читать, где какая масть.
- **Клик / тап по карте** — пометить её вышедшей (карта бледнеет и перечёркивается).
- **Повторный клик** — вернуть карту в игру (если ошиблись).
- Кнопка **«Сбросить»** — мгновенно возвращает все карты в игру.
- Счётчик **«В игре: N / 36»** в шапке и счётчик оставшихся карт в каждом ряду масти — обновляются в реальном времени.
- Состояние сохраняется в `localStorage`, поэтому можно продолжить после перезагрузки страницы.
- Mobile-first адаптивная вёрстка: на телефоне все 36 карт видны сразу на одном экране — по 9 карт масти в линию; на планшете и десктопе (≥860 px) карты становятся крупнее, подпись масти выносится влево от ряда.
- Тёмный современный дизайн, красные масти (черви/бубны) и чёрные (пики/кресты), плавные анимации.

## Технологии

Чистые **HTML + CSS + JavaScript**, без сборки и зависимостей.

## Запуск локально

Откройте `index.html` в браузере либо запустите любой статический сервер:

```bash
npx serve .
# или
python3 -m http.server 8000
```
